    Labgrid Backend

    These pages explain how hw-test uses labgrid.

    They are practical notes for this repository. When you need the full syntax for resources, drivers, places, or command-line options, use the labgrid documentation.

    The short version is:

    • an exporter is connected to the physical board,

    • the coordinator knows which resources belong to each place,

    • an envs/<place>.yaml file tells hw-test how to use that place,

    • a client shell or CI job acquires the place before it drives power, GPIO, OpenOCD, SSH, or the console.
