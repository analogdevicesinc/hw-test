API reference

The hw_tests package holds the code shared by all tests: reserving a board, building the test context, fetching firmware, and setting up SSH. Tests import it instead of calling labgrid, GitHub, or Cloudsmith directly.

  • LabgridClient

    Reserve a labgrid place and access its target.

  • Test executor

    Build the test context and select the tests to run.

  • Artifact storage

    Download build artifacts from GitHub and Cloudsmith.

  • Firmware Images

    Resolve firmware images by role.

  • SSH authentication

    SSH access to exporter and target hosts.

  • Logging

    Logging setup and redaction.
